# steam-go

[![Go](https://github.com/Jleagle/steam-go/workflows/Go/badge.svg)](https://github.com/Jleagle/steam-go/actions)
[![GoDoc](https://godoc.org/github.com/Jleagle/steam-go?status.svg)](https://godoc.org/github.com/Jleagle/steam-go)

## Packages

- `steamapi`: The main package for interacting with Steam's various APIs.
- `steamid`: Tools for parsing and converting between SteamID formats (SteamID2, SteamID3, SteamID64).
- `steamvdf`: A parser for Steam's KeyValue (VDF) text and binary formats.
